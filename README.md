# DSA Practice App

A personal training tool for DSA-focused technical phone screens (Blind 75 / NeetCode 150 style). Problem library organized by pattern and difficulty, an in-browser editor with a test runner, a Blind Test mode that strips scaffolding to simulate interview conditions, and progress tracking across sessions.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
