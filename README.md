# DSA Practice App

A personal training tool for DSA-focused technical phone screens (Blind 75 / NeetCode 150 style). Problem library organized by pattern and difficulty, an in-browser Python editor with a test runner, Blind Test mode (single problems or curated sets) that strips scaffolding to simulate interview conditions, timed Mock OA sessions, per-pattern learning content, a per-user Study Plan with spaced-repetition pattern review, and progress tracking across sessions.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
